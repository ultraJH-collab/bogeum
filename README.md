# 보금

빌라·다가구·오피스텔 전월세 세입자를 위한 임대차 안전 앱. 계약 전 진단부터 퇴거 정산까지 한 흐름으로 돕습니다.

- **찾기** — 데모 지도와 매물 목록, 안전·주의·위험 필터
- **매물 상세** — 안심점수 도장, 헤도닉 AI 시세, 건축물대장, HUG 간이 진단, 중개보수 비교
- **안심진단** — HUG 126% 판정(근저당·선순위 보증금 합산), 8대 위험 체크리스트, 등기부 권리분석, 안심 특약
- **AI 문구 검토** — 집주인 문자·특약 문구를 붙여넣으면 위험 신호와 고쳐 쓸 문구 제안 (회원)
- **AI 상담** — 지금 보는 매물의 진단 결과를 참고해 답하는 상담 패널 (회원)
- **직거래** — 본인인증 → 조건 → 특약 → 서명·SHA-256 봉인 → 에스크로, 등기 감시 시뮬레이션
- **사진 금고** — 4구역 12지점 입주·퇴거 사진, 해시·머클 루트, 감가상각, 인쇄용 소명 리포트
- **계정** — 아이디·비밀번호만으로 가입/로그인(이메일 인증 없음), 찜·계약·사진·대화 클라우드 저장

매물·등기·실거래는 모두 데모 데이터이고, 본인인증·은행 에스크로·결제는 화면상 시뮬레이션입니다.

## 실행

```bash
node server.js
```

→ http://localhost:5180 · `.env`에 `OPENAI_API_KEY`가 있어야 AI 기능이 켜집니다.

## 구조

```
index.html            앱 셸 (데스크톱 좌측 레일 + 모바일 탭바)
css/app.css           디자인 토큰, 모바일 → 데스크톱 반응형, 인쇄 스타일
js/config.js          Supabase URL · publishable 키 (공개값)
js/data.js            데모 매물 10건, 특약, 사진 금고 체크포인트, 감가상각 참고값
js/engines.js         헤도닉 시세, HUG 판정, 8대 위험 진단, 중개보수, 감가상각, SHA-256·머클
js/account.js         아이디/비밀번호 계정, 상태 동기화 (Supabase RPC)
js/app.js             해시 라우터와 화면 전체
js/ai.js              AI 상담 패널, AI 문구 검토
api/ai.js             Vercel 서버리스 함수: 세션 확인 + 하루 사용량 차감 → OpenAI 스트리밍
server.js             로컬 개발 서버 (정적 파일 + /api/ai)
supabase/migrations/  계정·세션·상태·AI 사용량 스키마
```

## 배포 (Vercel)

빌드 없이 루트를 정적 사이트로, `api/ai.js`를 서버리스 함수로 배포합니다. 환경변수 `OPENAI_API_KEY`(필수), `OPENAI_MODEL`(선택, 기본 `gpt-5-mini`)을 Vercel 프로젝트에 설정하세요.

```bash
npx vercel deploy --prod
```
